# THEATER-WORDS 剧场用语对照表

> v4.6 卡文胜负词清洗。产品语言=剧场：两人是同台演员，不是对手。**保梗不保罚**——趣味机制、
> 表演桥段、滑稽后果全保留；只剔除"分出输赢 + 输家受罚/赢家得利"的对抗框架。
> 守卫：`build.js` schema 段黑名单 `/(输|赢|罚|评分|猜拳|平票)/`（命中即构建失败）；
> `tests/data-engine.test.js` 同步断言防回潮。

## 一、对照表（禁词 → 剧场译法）

| 禁词 | 剧场译法 | 用法 |
| --- | --- | --- |
| 输 / 输家 / 演砸了 | **加演一段** | 后果不再是"败"，是"再来一段"；表演本身就是梗 |
| 罚 / 惩罚 | **彩蛋任务** | 强制性的"罚你"改写成自动触发的加更任务 |
| 评分（带奖惩） | **掌声** | 打分定奖惩 → 鼓掌/验收/点评，不给人打分定级 |
| 赢 / 赢家 | **荣任角色**（点单大使/选剧导演/价格锦鲤…） | 赢来的特权 → 轮到的舞台角色，另一位配对手戏（颁奖嘉宾/观众） |
| 猜拳定归属 | **抽签定角色** | 运气决定分工而非"比高低"，抽中即主演 |
| 平票算 X 赢 | **双人同台** / 收进《家庭吹牛史》 | 不裁决归属，两个版本都上桌 |
| 三局两胜 / 谁先 X 谁输 | 开演一轮 / 谁先笑场谁加演 | 竞赛轮次 → 剧场场次 |

## 二、判定规则

1. **必改**：text 命中黑名单正则（构建会失败）。
2. **判断改**：无禁词但存在"结果→对人施加"的结构（低分洗碗/深蹲罚/赢家命令对方/输家位），按上表改写。
3. **复核保留**（无害语境，不误伤）：`f09`/`r05`/`m09` 的"打分"无奖惩、纯玩梗；`p12` "满分"=无条件夸；
   `r01`/`r03`/`r06`/`p06`/`w05`/`n05`/`n06`/`n02` 为旅途分工、加演段目、共创接力或无败者的小特权；
   `p02` 冰淇淋是共享请客非受罚。

## 三、修订卡清单（24 张，2026-10-05）

### cards-travel.json（13 张）

- **g05** 笑场不算输，忘写日期才算 → 笑场不叫演砸，忘写日期才算。
- **g06** 谁先笑谁输。输的人要补一句…三局两胜，最后一局不管谁赢 → 先笑场的人加演一句『你眼睛真好看』再开演一轮；哪一轮两人都绷住了，就十指相扣收场。
- **f01** 让本人给『像不像』打分，低于八分加演一场，满分奖励免骂金牌 → 本人验收：点头就过审，笑到拍腿就加演一场；过审当场颁发免骂金牌（去掉分数，保"加演"与金牌梗）。
- **f02** 谁先把故事编圆谁赢 → 故事编圆就圆满杀青；学三声猫叫的梗保留。
- **f03** 对方当评委打分。输的人今晚要用失败截图当表情包 → 对方负责掌声点评；各自选一张神还原截图当专属表情包连发三天（惩罚变共同梗）。
- **f04** 笑场罚夸对方一句 → 笑场就加夸对方一句。
- **f06** 谁先绷不住…满足对方一个小要求 → 自动接下一个彩蛋任务——替对方跑一次腿。
- **f07** 接不上或说了人话的人输。输家用京剧腔唱… → 接不上或说了人话就加演一段：京剧腔唱『是我错了』，对方负责掌声雷动（京剧梗全保留）。
- **f12** 卡壳的人做五个深蹲 → 卡壳的人加演一段：边做五个深蹲边举茶杯敬礼（深蹲从罚变成舞段）。
- **p05** 被抓到罚请一次奶茶 → 被抓到就触发彩蛋任务：请对方喝一杯奶茶。
- **p08** 谁先打字谁输 → 谁先打字就要给对方语音配音一张。
- **r02** 编得最离谱的人赢得零食点单权 → 编得最离谱的人荣任下一站零食点单大使。
- **r08** 编的部分多的赢 → 更离谱的那版收进《家庭吹牛史》。

## 四、体力标记（stamina）

- 规则：每张卡 `stamina: "high" | "normal"`；high=深蹲/久站做饭/大扫除冲刺/逛街试穿跑动/60 分钟户外或买东西跑动类。
- high（11 张）：`f08` `f09` `f12` `g11` `h10` `h12` `m04` `m10` `p09` `p12` `r11`；其余 85 张 normal。
- 引擎能力：`pickDaily(cards, date, energy, {noStamina:true})` / `drawFromSuit(cards, suit, excludeIds, rnd, {noStamina:true})`
  滤掉 `stamina==='high'`；不传 opts 行为与旧版完全一致（旧数据无 stamina 字段也不会被滤）。调用点接入由 K4 负责。
