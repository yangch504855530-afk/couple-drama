# v1.2 增量需求 — 节奏主权与今日需要 (REQUIREMENTS v1.2)

- 日期: 2026-09-30 ｜ 状态: 评审通过
- 北极星: **推动关系善意发展**。一切指标（连击/成就/节奏）都不得成为压力源；持久性与稳定性优先于功能数量。
- 来源: 用户启发（卡牌化+节奏自定义）+ 需求全景调研（NEEDS-RESEARCH.md）+ 计分制评审（POINTS-RESEARCH.md 八要素）

## 1. 用户故事

| # | 作为… | 我想要… | 以便… |
|---|---|---|---|
| US-1 | 怕被打卡绑架的人 | 自己设定演出节奏（每天/两天/三天/每周一抽） | 游戏跟着我的生活走，不是我跟着游戏走 |
| US-2 | 想保持低压力的人 | 非演出日游戏不催我；想提前演也随我 | 节奏是承诺不是枷锁 |
| US-3 | 想让需求被看见的人 | 每天自报"今天我最需要的一件事"，对方可见 | 不用等对方猜（自报、一件事、无分值） |
| US-4 | 收藏爱好者 | 演过的戏码变成带卡面的收藏，越攒越像"我们的剧场纪念册" | 关系的正向积累可视化 |

## 2. 功能需求

- **FR-A 节奏主权（Cadence）**: 每人（共享一份，双人协商）可设演出节奏 ∈ {每天 1, 两天 1, 三天 1, 每周 1}，随时可改；连击按**节拍**计算——间隔 ≤ 节奏天数即延续，绝不因"没到节奏日"清零；休演/停演不惩罚（继承 v1.1）。
- **FR-B 非演出日轻提示**: 未到节奏日时今日剧场显示"下一场 X 天后"，抽卡按钮显示剩余天数；**不锁定任何功能**——提前演完全允许，且节奏从当天顺延（自主支持原则：节奏是自我承诺不是枷锁）。
- **FR-C 今日需要（无分数版需求共享）**: 每人每天可自报 1 件今日最需要的事（从 8 项需求一键选 或 自由填 ≤30 字）；对方可见并附充能提示；**只能本人自报**、零点重置、今日免检时隐藏、不填完全合法；**无排名、无分值、不可比较**。
- **FR-D 卡牌收藏感**: 四/八字色各有专属卡面花纹；演出过的卡在日志中带完整卡面；抽卡展示带"开卡"仪式感（翻牌动画级别简化为卡面高亮）。
- **FR-E 持久性红线**: 存档结构变更必须向后兼容（老存档自动获得默认节奏=1 天）；引擎纯函数化；节奏计算有专项测试（跨月/自由顺延/休演交互）。

## 3. 避坑清单（来自 POINTS-RESEARCH.md，一票否决项）

不做：积分/兑换/排行榜/Top3 分值/体力值扣减/投入审计仪表盘/催促推送/评分制。
原则：自报、一件事粒度、每日重置、免检出口、不可比较、节奏=自我承诺。

## 4. 验收

盲评 F（画像：节奏焦虑者，重点测"改节奏/停几天再回来会不会有心理负担"）；节奏计算逻辑由单元测试穷举（1/2/3/7 天 × 跨月 × 休演 × 提前演）。
