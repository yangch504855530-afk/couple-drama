# 低成本推广方案 (2026-10-02)

- 方法:2 路并行联网调研(爆款传播路径拆解 / 内容模板与承接方案),每条标注【实证】/【推断】
- 核心参照:哄哄模拟器(同为情侣吵架主题网页,24h 60 万用户)作者王登科的一手复盘

## 一、最重要的一手案例:哄哄模拟器是怎么引爆的【实证】

1. 作者第一天自己发在微博/即刻/X/V2EX——**全部反响平平**,部分社区还有负评。开发者社区只是"种子登记处",不是引擎。
2. 引爆点是**第二天一个 QQ 空间帖子数千转发 → 被用户自发搬进无数 QQ 群**,主力是 00 后/10 后大学生。"没有任何一个外部渠道来自网站链接或搜索引擎"。
3. 转发动机(作者原文):"它可以被截图,可以炫耀"。测试类 H5 是刷屏率最高的品类(腾讯云 H5 案例统计),机制=结果可晒+拐着弯夸人+结果组合多样不撞款。
4. 代价:腾讯**当晚 9 点就封了网页**(测试类内容是微信明文限制类目),"封禁-申诉-解封"反复三四次。
5. 作者半年后复盘:"如果'能火'可以被方法论,字节应该做一个成一个"——**推广方案只能提高概率,不能保证引爆;方案的目标应设为"把产品送到 20-50 对真实情侣面前",不是爆款。**

其他可参照案例:小猫补光灯(小红书单条争议笔记 118 万阅读→3 天 3 万下载)、文风测试/OC 成分分析器(QQ 转发链,结果页可截图→30 万访问)。共性【推断】:第一批 1000 用户几乎都来自**单一平台单条内容起爆后的 24-72 小时**,不是多平台铺量。

## 二、推广前置地基(不修则推广漏一半,合计约 1 天,零成本)

| 动作 | 依据 |
|---|---|
| 1. 托管迁移 GitHub Pages → **腾讯 EdgeOne Pages**(免费、免备案、国内可达) | 【实证】github.io 被 GreatFire 判定大陆屏蔽+间歇超时;微信内 github.io 弹"非微信官方网页"先导页,未备案域名可被拦到"复制到浏览器"。EdgeOne 免费额度:40 项目/500 构建/月/KV 1GB/Edge Functions 300 万次/月 |
| 2. 首屏入口简化:隐藏/降级 GitHub token 绑定,主打"**一台手机,打开就玩**"(同框模式) | 【推断】绑定+token 是双门槛起量杀手;哄哄模型=零门槛打开。绑定可留在深处给重度用户 |
| 3. 加统计:页面挂 **51.LA V6**(免费 300 万 PV/月,支持来源+自定义事件);前台计数可选 Vercount(免费、国内直连) | 【实证】51.LA 是国内最稳免费统计;Cloudflare Analytics 国内不稳(SSL 污染+被 AdBlock 屏蔽);不蒜子老域名多次挂掉 |
| 4. 不同渠道用不同 URL 参数(?from=xhs / ?from=qqwall),51.LA 可区分来源 | 【推断】零成本归因 |
| 5. index.html 文案与实际版本对齐 | 现状:文案停在 v2.2,js 已是 v3.0 |

## 三、渠道打法(按优先级)

### 路径 1(主攻):QQ 生态——学生情侣聚集地【实证:唯一被验证的情侣网页引爆场】

- 大学表白墙投稿:10-20 所高校,单条 1-3 元或免费(【实证】中青报:87.12% 大学生用过校园墙)。话术包装成"情侣挑战/和对象试了,第 X 个笑疯了",附截图。
- QQ 群/QQ 空间:混进大学生恋爱/脱单/校园群,以用户口吻(非广告口吻)发截图+"谁来和我对象试试"。【实证】QQ 空间内点链接无微信拦截页。
- 微信端**只走图片**:结果截图/海报(可带二维码)发私聊和朋友圈;**不做**链接群发、**不做**任何"分享解锁"文案(【实证】诱导分享初犯即封 30 天+拦链接;测试类是微信明文受限类目,哄哄当晚被封是前车之鉴)。

### 路径 2(内容引擎):小红书情侣赛道【实证:优势流量赛道,零成本】

- 笔记形态(按爆款案例优先级):
  1. 清单型:"情侣间必做的 N 件小事"(对标案例 4.1 万赞/4.2 万收藏)——把 50 件校园小事内容做成图文清单,文末"转给对象"
  2. 聊天记录风/真实体验风:和对象真玩的过程截图、"第 3 张卡我笑到捶床"(【实证】聊天记录截图封面是五大爆款封面之首)
  3. 可留一个争议点撬评论("这有什么用?")——小猫补光灯 118 万阅读笔记即争议驱动【实证】
- 发布:20:00-23:00(情感类情绪黄金时段),每日≤2 篇、间隔≥3 小时【实证】
- 承接(2025-03 新规后):**私信自动回复留联系方式=必挂**【实证】。合规路径:①评论区置顶"进群领链接"→小红书站内群聊(当前公认最稳)→群公告放地址;②个人简介写产品名引导搜索;③正文绝不贴外链/二维码

### 路径 3(种子层,第 1 天顺手做):即刻/V2EX 分享创造/少数派

- 预期只是几十个种子用户+第一批反馈(哄哄第一天全网平平,别指望起量)【实证】
- 关键动作(被哄哄验证):页面放"联系开发者"通道,为可能的引爆预留归因和舆情承接

### 明确不做(现阶段)

- 微信小程序:个人主体"工具"类目排除"用户自定义内容记录及分享",情侣互动有审核反复风险;小游戏通道需软著+ICP 备案(7-20 工作日),流程重。等 H5 被验证有真实留存后再考虑【实证类目条款】
- 付费投放、KOL、抖音(外链封号风险+制作成本高)

## 四、唯一建议破例的产品改动(增长管道,非产品功能)

做一个"**戏精战报**"分享图:每场演出结束可生成一张图(今晚演了什么戏码+一句最炸的台词+产品名),保存到相册。依据【实证】:测试类刷屏的机制就是"结果页可截图炫耀+拐着弯夸人";QQ 群转发的最小单位就是"一张截图+一句话"。产品本身的"好玩"内容(抽卡翻车/神回复)就是素材。
