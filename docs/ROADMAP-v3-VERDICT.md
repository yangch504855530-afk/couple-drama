# v3.0 规划三方评审裁决 (ROADMAP-v3-VERDICT)

- 评审: U1 流失用户 / U2 产品总监 / U3 目标用户代表 ｜ 裁决: PM
- 总体: U1 30-35% / U2 5/10 "骨架对关节脱臼" / U3 6.5/10 "最大的洞是不做推送"
- U2 最深刻警告（必须吸收）：**全量可见只会让沉默有据可查**——同步把"想要陪伴已送达 14 天未回应"变成带时间戳的冷暴力证据

## 三方共识（直接采纳）

1. 时间胶囊 = 唯一自带回访理由的功能（三方一致，U3 只留一个功能投给它）
2. 全量同步 = 地基不是功能（三方一致），但必须带边界（U2）
3. 剧情卡必须嵌入流程（顺带补一句），不能是独立任务（U1 互惠揭示 + U3 顺带写）
4. 解绑/分手设计是信任地基（U2 人质陷阱警告）
5. 胶囊信件全文不上云（U1 隐私）——元数据同步、全文留本地

## 分歧裁决

| 议题 | 分歧 | 裁决 |
|---|---|---|
| 推送/提醒 | U1:绝对禁令是自杀条款；U3:靠对方看到🔒替我提醒 | **页面内触达**：到期日解锁页顶部显眼"有信可拆"；对方状态区常显"🔒 有信 N 天后可拆"——让共享可见性成为人肉提醒，不做系统推送 |
| 沉默可视化 | U2:同步让沉默有据可查 | 递台阶**回执状态仅本人可见**；心情标记不做；夸夸无对比排行；等待天数仅自己侧 |
| 解绑确认 | U2:任一方可拒确认扣住数据=人质陷阱 | **任一方单方可强制解绑**，无需对方确认；本地数据无条件归本人 |
| 胶囊解锁期 | U1:1 年太重；U3:1 月档卡见面节奏 | 默认 1 周，可选 1 月；1 年档隐藏（进阶） |

## v3.0 最终实现范围（裁决后）

1. **全量状态同步**：每日数据/things/praise/log 进 Gist room.state（双方各写各的 side，拉取合并），互惠揭示（写了我的才解锁 TA 的同日感想）
2. **时间胶囊**：全文仅本地（隐私），元数据（有信+解锁日）上云让双方可见倒计时；默认 1 周/可选 1 月
3. **递台阶回执仅本人可见**（拆冷暴力证据链）
4. **解绑强制单方权 + 30 天共同导出窗口**
5. 角色分配保留（A2 样本单一不足以全局降级——U2 审计采纳）
