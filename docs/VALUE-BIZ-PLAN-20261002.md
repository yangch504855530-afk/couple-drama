## 一、战略重构:用"时刻复购"替代"习惯留存"

放弃留存目标后,商业逻辑反而顺了——这个品类的全部变现证据都不在"时长"里,在"时刻"里:

-【实证】实体情侣卡牌是全球唯一持续卖钱的形态(TableTopics 16 年 400 万套),卖的是**送礼时刻**,复购靠节日/纪念日,不靠日活;
-【实证】WishCupid 道歉网页收钱,卖的是**和好时刻**;
-【实证】LoveBook 280 万客户,卖的是**纪念时刻**(回忆实体化);
-【实证】OurRelationship $99-249,卖的是**危机时刻**(关系急救);
-【实证】唯一跑通订阅的 Paired,靠的是日更内容供给——我们不做。

**所以:产品 = 免费的关系价值引擎(信任+获客+传播),商业 = 按时刻付费的 SKU 阶梯。** 每个时刻是一个复购触发器:节日→礼盒,吵架→急救包,周年→纪念册。情侣一辈子不"常驻",但一辈子有这些时刻。

## 二、维系关系:功能与关系科学的映射(全部免费,这是产品存在的理由)

| 功能 | 关系机制 | 证据强度 | 状态 |
|---|---|---|---|
| 演一场(96 卡小剧场) | Aron 2000:共同新颖活动提升关系质量 | 实证(JPSP,三项实验) | 已有 |
| 递台阶 | Gottman:修复尝试是关系存亡的第一预测因子 | 实证(50 年临床) | 已有,**永远免费**(获客器,商业红线) |
| 演完互夸一句(收尾动作) | Gottman 5:1 正负互动比 | 实证 | 已有 |
| **好消息频道(新增)** | Gable 资本化研究:对"好消息"的积极回应比坏消息支持更能预测关系质量;回法四种(热情/提问/放大/庆祝)有脚手架 | 实证 | **新增,替代被砍的需求条**:同框免绑定、无义务感,一人说一件今天的好事,对方按四种回应法接住——把"回应卡"的正确内核用同框方式重做 |
| **每周仪式(新增)** | Gottman 每周关系会议(20 分钟):谢一件事/聊一件心事/定一件下周开心事 | 实证(会议结构降低冲突升级) | **新增**,放百宝箱,opt-in 不打卡;给"里程碑时刻"(周年/每月一次)一个正式载体 |
| 免战牌/休演/节拍 | 反内卷红线(义务化是品类毒药,恋爱记实证) | 实证(反面) | 保留为规则 |

设计总原则:**每个功能都对应一条可引用的关系科学机制,产品页明示出处**——这既是维系价值,也是商业信任背书(和 Gottman Card Decks 的免费内容营销同构)。

- **不做**:订阅、广告、返现、社交曝光(与反内卷红线一致,BUSINESS-RESEARCH 已裁决)。
- **客观天花板**:国内实体情侣卡是碎单品类(单品生命周期数百-数千套,客单 ¥20-60)【实证】——按此推算年营收量级是**几万到十几万的小而美生意,不是创业公司生意**【推断】。这个预期必须先立好,否则动作会变形。
- **成本路径(推断)**:淘宝定制印刷 100 套起印,卡牌+盒小批量成本约 ¥15-25/套,礼盒定价下毛利成立;先预售验证再备货,零库存风险。

## 五、一句话定位与 5W1H

**一句话:**
> 双人戏精,是给"喜好不同、懒得设计仪式"的情侣的一台手机小剧场:想一起玩时抽张卡演一场、吵完架递个台阶、睡前互夸一句——15 分钟,把 50 年关系心理学验证的维系方法,变成像玩游戏一样好玩的日常时刻。

| 维度 | 内容 |
|---|---|
| **Who(给谁)** | 喜好不同、想维系感情但没精力设计仪式的情侣(18-30 岁为主;同框场景优先) |
| **What(是什么)** | 一台手机就能玩的情侣关系卡牌引擎:96 张戏码卡+递台阶+互夸+关系仪式,网页打开即玩、免费 |
| **When(何时用)** | 三个时刻——周末晚上想一起玩/吵架后想和好/睡前与纪念日想表达(复购也发生在这些时刻) |
| **Where(在哪用)** | 沙发、餐桌、旅途酒店——一台手机递着用;线上靠战报截图在聊天记录里流转 |
| **Why(为什么存在)** | 关系心理学 50 年实证:关系靠"一次次小时刻"存出来(修复尝试/5:1/新奇共同活动),情侣缺的不是道理,是把道理变成零门槛好玩仪式的工具 |
| **How(怎么用/怎么赚)** | 用:抽一张卡→演→笑→互夸→存战报,吵架了递台阶;赚:免费引擎+按时刻付费——送礼买卡牌礼盒(¥39.9-69.9)、和好买急救包(¥9.9)、周年买纪念册(¥19.9),不做订阅不做广告 |
