# 大学生版删减设计 (CAMPUS-SCOPE)

- 日期: 2026-09-30 ｜ 版本: v2.0-campus 草案
- 目标人群: 中国大学生情侣（18-24 岁，含异地恋）
- 状态: **初稿（待 3 项调研回充后裁决）** — 标注 ⏳ 的判断需调研验证

## 0. 人群画像假设 ⏳

生活费 1500-3000 元/月；异地恋比例高（寒暑假/两校）；手机重度用户（微信/QQ/小红书/抖音）；为"仪式感"花钱（为对方 > 为自己）；反感"双绑下载"和订阅制；吵架多为小事（回消息慢、游戏时间、见面频率）。

## 1. 删减清单（直接砍）

| 现功能 | 理由 | 处置 |
|---|---|---|
| 角色分配（职场版 8 角色） | 司机/财务大臣与大学生无关 | **校园化改造**而非删除：自习监督员/食堂情报官/晚安播报员/跑腿代办员/八卦记者/队医 等 8 枚校园角色 |
| 需求条"驾驶余量" | 大多数学生无车 | 改为"自习余量"（图书馆/考试周语境） |
| 公路戏 12 张卡 | 无车场景 | **改造为"异地戏"**：高铁相见/车站接站/视频贴贴/周末计划——异地恋是大学生高频场景 ⏳ |
| 消费戏高价卡 | 预算不符 | 预算上限降为 50 元内；砍 ¥99+ 档 |
| 页签冗余 | 极简诉求 | 四页签 → **三页签**：我们（今日+需求体检）/ 卡池 / 日志（成就并入） |

## 2. 保留清单（v1.1-1.2 验证过、大学生同样需要的）

递台阶（小事吵架更需要）· 免战牌 · 今日需要（异地恋神器：告诉对方我今天要什么）· 夸夸存折 · 关系气候 · 今晚电量（改考试周语境）· 节奏主权 · 无输赢规则 · 反内卷底线

## 3. 新增清单（大学生特有）⏳ 待调研确认优先级

1. **恋爱天数 + 纪念日倒数**（QQ 情侣空间最高频功能的等价物）——头图常显"在一起 N 天"
2. **100 件校园小事清单**（抖音爆款现象的网页化）：一起自习/一起夜跑/食堂第三窗口/期末互相抽背——每完成点亮一枚，收集进度可分享
3. **异地恋模式开关**：开启后每日剧本偏向"视频可完成"卡、显示"距下次见面 X 天"（手动设定）
4. 每日一问（异地破冰）—— 若 Paired 模式验证成立

## 4. 极简原则

- 首屏只保留 3 个动作：今日需要 / 抽一张 / 递台阶（其余全部收进"更多"）
- 全部功能离线可用；不注册不登录；单人可玩（双人同框为增强）
- 文案全面校园化（自习/食堂/宿舍/考试周），删除职场/驾驶隐喻

## 5. 商业化假设 ⏳ 待调研验证

免费全功能铺量（学生付费力低但传播力强）→ 变现：实体"100 件校园小事"卡牌（¥29-49，抖音/校园代理分销——抖音已验证该品类）+ 小额主题卡包（¥6-18）+ 文创联名。**不做**订阅、不做广告、不做现金打卡。

## 6. 待调研裁决项

- 100 件小事清单的优先级（是否进 v2.0 首版）
- 异地恋模式开关是否首版即做
- 公路戏改造 vs 直接砍
- 三页签 vs 四页签
- 商业化第一刀（实体卡牌 vs 小额买断）

## 调研裁决（2026-09-30，3 个调研 agent 回充后）

### 最终删减/改造裁决

| 项 | 裁决 | 依据 |
|---|---|---|
| 恋爱天数+纪念日倒数 | ✅ **新增，头图常显** | 三调研交叉：功能适配"最高频，独立工具可存活"+需求清单第 4 条 |
| "想你"轻互动按钮 | ✅ **新增（<3 秒）** | 功能调研必留 Top6：每日轻互动成本<3 秒 |
| 100 件校园小事清单 | ✅ **新增 50 条首版** | 消费调研：唯一被平台销量验证的品类（350+ SKU/5-15 元）；需求清单第 6 条 |
| 需求条校园化 8→6 | ✅ | 吵架 TOP=游戏时间/回消息（非职场话题）——"想要陪伴"替代"驾驶余量/掌控感" |
| 角色校园化改造 | ✅ 8 枚换文案 | 调研：司机/财务大臣与大学生无关；"改造优于删除"保留协作仪式 |
| 公路戏 → 异地戏 | ✅ 12 张改文案 | 需求清单第 5/10 条：异地恋"没话说"+见面规划 |
| 递台阶/今日需要/免战/节奏/存折 | ✅ 原样保留 | 需求清单第 8 条直接命中递台阶；第 9 条命中单文件轻应用 |
| "关系管理"入口升级 | ✅ | 致命雷区 5：解绑困难/分手数据纠缠是强负面记忆点 |
| 强制双绑/定位/返现/社交曝光 | 🚫 永不做 | 致命雷区 1-4（小恩爱恩爱银行崩盘实锤） |

### 商业化裁决（消费调研）

价格甜蜜点：日常 ¥6-18、节日礼盒 ¥39-59、¥99+ 失效。路径：免费全功能铺量 → 实体"50 件校园小事"卡牌（¥19.9 引流/¥49.9 礼盒，唯一被销量验证品类）→ 小额主题卡包。不做订阅/返现/广告。先免费铺校园量（表白墙/小红书清单内容），实体化等自然需求出现再上。
